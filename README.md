# 🌐 LanScan — Мережевий Сканер & IP-Трекер Комп'ютерів

Простий, сучасний та блискавично швидкий веб-сайт для сканування, моніторингу та відстеження IP-адрес усіх комп'ютерів і пристроїв у вашій локальній мережі.

---

## ✨ Основні можливості

- ⚡ **Швидке апаратне сканування (SendARP)**: сканує всю підмережу (254 адреси) за лічені секунди. На відміну від звичайного `ping`, який часто блокується брандмауером Windows, апаратний ARP працює надійно для 100% активних пристроїв.
- 🔘 **Кнопки зверху та знизу**: запустіть або повторіть сканування як із верхньої панелі сайту, так і знизу під списком знайдених пристроїв.
- 💻 **Розпізнавання типів пристроїв**: автоматично визначає, чи це комп'ютер / ПК, роутер, смартфон, розумний пристрій (IoT) або принтер.
- 🏷️ **База виробників (OUI)**: визначає бренд пристрою (ASUSTek, MSI, Apple, Samsung, Intel, TP-Link, Xiaomi, Tuya тощо).
- 📝 **Відстеження та власні назви (IP Tracker)**:
  - Запам'ятовує кожен комп'ютер за його фізичною MAC-адресою.
  - Дозволяє призначити кожному комп'ютеру власну назву (наприклад, *"ПК Івана"*, *"Робочий Ноутбук"*, *"Сервер"*) та коментарі.
  - Фіксує час першої появи в мережі та останній візит.
- 🟢 **Живий статус та пінг**: пульсуючий індикатор онлайн/офлайн та час відгуку в мілісекундах (`ms`).
- ⏱️ **Автоматичне періодичне сканування**: можливість увімкнути авто-скан кожні 1, 5 або 15 хвилин.
- 🔍 **Миттєвий пошук та фільтри**: фільтрація за назвою, IP-адресою, MAC або виробником; швидкі фільтри *"Тільки онлайн"*, *"Тільки комп'ютери"*, *"Обрані"*.
- 📥 **Експорт**: вивантаження списку комп'ютерів у форматі CSV (для Excel) або JSON.
- 📋 **Копіювання в 1 клік**: швидке копіювання будь-якої IP-адреси або MAC-адреси.

## 🚀 Як запустити сайт

### Варіант 1: Через файл запуску (Найпростіший спосіб для Windows)
Просто двічі клацніть файл:
```bat
start.bat
```
Він автоматично запустить сервер та відкриє сайт у вашому браузері за адресою **`http://localhost:8050`**.

---

### Варіант 2: Через командний рядок Python
Відкрийте термінал у цій папці та виконайте:
```bash
python run.py
```
або
```bash
uvicorn lanscan.main:app --host 0.0.0.0 --port 8050
```

> **Порада**: оскільки сервер запускається на `0.0.0.0`, ви можете відкрити цей сайт з будь-якого іншого комп'ютера або телефона у вашій мережі, ввівши IP-адресу цього комп'ютера: `http://<ваш-локальний-IP>:8050` (наприклад, `http://192.168.50.249:8050`).

```text
for-ivan/
│
├── lanscan/                     # Основний бекенд-пакет

│   ├── scanner.py               # Двигун сканування мережі (SendARP + порти + DNS)
│   ├── database.py              # Робота з базою SQLite (збереження історії та назв)
│   ├── oui_data.py              # Вбудована база виробників MAC-адрес (OUI)
│   └── templates/
│       └── index.html           # Головна сторінка веб-інтерфейсу (Tailwind CSS)
│
├── static/
│   ├── css/
│   │   └── style.css            # Стилі інтерфейсу та анімації
│   └── js/
│       └── app.js               # Клієнтська логіка, SSE, фільтри, редагування
│
├── data/
│   └── devices.db               # Локальна база SQLite з історією відстеження
│
├── requirements.txt             # Залежності Python (FastAPI, Uvicorn, psutil)
├── start.bat                    # Файл швидкого запуску в 1 клік для Windows
├── run.py                       # Альтернативний скрипт запуску на Python
└── README.md                    # Ця інструкція
```

## 🛠️ Використані технології

- **Бекенд**: Python 3.9+, [FastAPI](https://fastapi.tiangolo.com/), Uvicorn, SQLite3, Windows `iphlpapi.dll` (`SendARP`).
- **Фронтенд**: HTML5, Tailwind CSS, сучасний JavaScript (Vanilla JS без важких фреймворків), Server-Sent Events (SSE).
